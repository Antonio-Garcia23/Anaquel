# ui

Componentes reutilizables y el sistema de diseño. Los tokens de color van en `src/ui/theme`, y son los únicos colores que pueden usar los componentes (nunca un hex directo).

- Tema claro por defecto, oscuro opcional.
- Literata para títulos, Figtree para el resto.
- Área táctil mínima de 44px.
