# Anaquel

Una app que funciona como biblioteca virtual. Permitiendo añadir libros por codigo de barras o manualmente. Sirve para organizar las bibliotecas fisicas.

Biblioteca personal para iOS y Android, hecha con [Expo](https://expo.dev) y Expo Router.

## Empezar

```bash
npm install
npx expo start
```

Las pantallas viven en `src/app/` (rutas basadas en archivos).

## Verificar

```bash
npx tsc --noEmit
npx expo-doctor
npx expo lint
```
